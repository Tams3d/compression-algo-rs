# compression-algo-rs

A tiny Rust project for trying out compression ideas.

## Run

```
cargo run
```

It compresses some text, decompresses it.

## Files

- `src/lib.rs` — the library entry point.
- `src/algorithms/` — one file per algorithm (`rle.rs` to start).
- `src/main.rs` — a small example that uses the library.
